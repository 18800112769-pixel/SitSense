# SitSense

**离线摄像头坐姿距离监测，过近时静音小窗提醒你坐直。**

不联网 · 不保存任何画面 · 全程无声音 · Windows 桌面应用

</div>

---

## 这是什么

SitSense 用电脑摄像头观察你与屏幕的距离。以你校准时的正常坐姿为基准，当人脸在画面中持续明显变大（说明你凑近了屏幕），就在屏幕中央弹出一个安静的提示窗，写着"坐直"，几秒后自动消失，不打断你打字、不抢焦点、不发出任何声音。

它还提供口部状态提示：以校准时的放松嘴形为基准，检测到持续的嘴形异常变化时提示"撕嘴皮"，用于提醒咬唇、撕嘴皮一类的小动作。这是简化的嘴形变化提示，不是动作识别。

判断基于人脸尺寸比例，不换算厘米，不区分头前伸和整体前移，也不做姿势分类或健康诊断。

## 功能特性

- **个人校准**：自然坐直、放松嘴唇约 5 秒，建立属于你自己的距离和嘴形基准；基准保存在本机，下次启动自动加载，无需反复校准。
- **持续过近才提醒**：默认连续过近 30 秒才提示，短暂凑近不会打扰；两次提示至少间隔 5 分钟。
- **静音提示窗**：独立小窗只显示图标和文字，约 8 秒后自动消失；主窗口最小化、被其他软件挡住时照常弹出。
- **托盘驻留**：关闭或最小化主窗口只是隐藏到托盘，监测继续；双击托盘打开，右键可暂停、恢复或退出。暂停会释放摄像头。
- **参数可调**：设置页可修改过近阈值、提醒时长与间隔、摄像头索引与接口、分辨率，以及坐姿 / 口部 / 预览各自的开关。
- **低占用**：默认每秒识别 5 次，窗口最小化时跳过预览绘制，采集和推理在后台线程，界面不卡顿。
- **完全离线**：模型随程序本地运行，没有账号、没有遥测、没有自动更新、没有任何网络请求。

## 隐私

摄像头画面只在本机内存中用于即时判断，**不保存、不上传任何图像、视频、逐帧人脸关键点或表情系数**。

本地数据全部保存在 `%LOCALAPPDATA%\SitSense`，主要是：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 界面设置参数 |
| `calibration.json` | 校准后的数值基准和摄像头配置 |
| `statistics.sqlite3` | 汇总统计（如提示次数），不含画面 |

卸载程序不会删除这些数据；想彻底清除，手动删除该文件夹即可。

## 快速上手

1. 启动 SitSense，允许 Windows 的摄像头权限；关闭正在占用摄像头的会议软件。
2. 单人面对摄像头，调整到你平时的自然正常坐姿，保持屏幕角度不动。
3. 在"监测"页点击 **校准**，自然坐直、放松嘴唇、正视摄像头约 **5 秒**。校准中偶发的表情或转头会自动跳过，必要时最长延长到 8 秒。
4. 校准成功后最小化主窗口，正常办公即可。连续过近达到设定时长后，屏幕中央会出现静音提示窗。
5. 需要临时离开或开视频会议时，右键托盘图标选择 **暂停**（释放摄像头）；回来后 **恢复**。
6. 只有右键托盘选择 **退出** 才会真正结束监测。

更换使用者、挪动摄像头或调整屏幕角度后，建议重新校准。摄像头索引、接口或分辨率变化时，旧基准不会自动套用，需重新校准。

## 系统要求

- Windows 10 / 11，64 位（x64）
- 一个可用摄像头（普通笔记本内置摄像头即可）
- 无需安装 Python 或其他运行库
